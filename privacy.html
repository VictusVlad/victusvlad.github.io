Privacy Policy

Effective date: 2026-11-07

ProjectsHub is a private, single-user, read-only analytics tool operated by Vlad (the owner) for the owner's own accounts only.

Data accessed

With the owner's authorization, ProjectsHub reads analytics and metadata from the owner's own accounts through official APIs:

  • YouTube Data API v3 and YouTube Analytics API (read-only scopes), for the channels Studio HQ and Feltwick
  • Pinterest API, for @studiohq2
  • Etsy Open API, for the shop Studio HQ

No data about other people is collected. The tool never writes to these accounts.

Storage and use

Data is stored locally on the owner's machine only. It is used only to show the owner their own statistics. It is never sold, never shared with or disclosed to third parties, and never used for advertising.

Google API Services User Data Policy

ProjectsHub's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Data from Google APIs is used only to provide the owner's analytics view, is not transferred to others, is not used for advertising, and is not read by humans other than the owner.

Revoking access

  • Google/YouTube: remove ProjectsHub at myaccount.google.com/permissions.
  • Pinterest: remove the app under Settings, Apps (authorized apps) in the Pinterest account.
  • Etsy: remove the app under Account Settings, Apps (manage apps) in the Etsy account.

Deletion

Locally stored data can be deleted at any time by the owner. Deletion can also be requested by email and will be carried out promptly.
